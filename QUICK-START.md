## 🔍 If Browser Shows "Can't Reach Page"

### Solution 1: Clear Browser Cache
1. Press `Ctrl + Shift + Delete` in your browser
2. Select "Cached images and files"
3. Click "Clear data"
4. Try again: http://localhost:3000

### Solution 2: Try Different URL Format
- Try: http://localhost:3000
- Or try: http://127.0.0.1:3000
- Or try: http://[::1]:3000

### Solution 3: Use Incognito/Private Mode
1. Open a new Incognito/Private browser window
2. Visit: http://localhost:3000

### Solution 4: Check Windows Firewall
1. Search for "Windows Firewall" in Start menu
2. Click "Allow an app through Windows Firewall"
3. Make sure Node.js is allowed

### Solution 5: Restart Server
If the above doesn't work, stop and restart the server:
1. Press `Ctrl + C` in the terminal where server is running
2. Run: `node server.js`
3. Wait for "SmartTrack Commerce server running on http://localhost:3000"
4. Try accessing again

## ⚠️ Troubleshooting

### If products don't load:
1. Check browser console (F12) for errors
2. Verify server is running (check terminal)
3. Refresh the page (F5 or Ctrl+R)

### If images don't show:
- This is normal! Products use placeholder images
- You can replace them with real images later

### If login doesn't work:
1. Go to Sign Up page
2. Create a new account
3. Then login with your credentials
